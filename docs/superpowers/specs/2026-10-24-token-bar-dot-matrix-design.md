# 上下文占用条改为盲文点阵（nano-harness）

- 日期：2026-10-24
- 状态：已实现
- 关联代码：`core/tui/footer.py`（`token_bar_text` / `_dot_cell`）、`tests/test_ui_footer_approval_mode.py`、`smoke/footer.py`
- 关联文档：`docs/tui.md`、`core/tui/app.css`

## 1. 意图

页脚 `Context Usage:` 占用条按 20 格均分，每格 5%：50.0% 与 54.9% 渲染完全相同，短回合内的
上下文增长看不见。目标是把可见粒度细化到 1% 以内，同时保留「容量 + 占比」的直觉。

## 2. 已确认的决策

| # | 决策点 | 结论 |
|---|---|---|
| 1 | 编码方式 | 盲文点阵：20 格，每格 8 个点（2 列 × 4 行），共 160 档，一档 0.625% |
| 2 | 点亮顺序 | 每格从底部逐行向上、每行先左点后右点；末格按点亮点数呈现部分填充 |
| 3 | 满格 / 空槽字形 | 满格 `⣿`；空槽用空格（盲文空字形与空格同宽，空格更稳妥） |
| 4 | 颜色 | 不变：填充与末格按 40% / 80% 阈值绿→黄→红，空槽无色 |
| 5 | 未知上下文长度 | 保持原样 `[--------------------] -- / --`（灰），与 0% 的空条区分开 |
| 6 | 超限 | 条填满，百分比照实显示（如 `120.0%`） |
| 7 | 组件 | 不用 `textual.widgets.Sparkline`：它是时序 widget，`min==max` 时整条塌成基线，空槽渲染成 `▁`，且逐值混合颜色，无法整条分档染色；一行高度下其算法等价于「每列挑一个块字符」，直接手算即可 |

## 3. 备选与取舍

| 方案 | 粒度 | 取舍 |
|---|---|---|
| 盲文点阵（采用） | 0.625% | 纹理轻、非实心；盲文字形自带格间缝，无法去除 |
| 八分块横向填充 `▏▎▍▌▋▊▉█` | 0.625% | 无缝、轮廓直；仍是实心填充 |
| 网点纹理 `░▒▓` | 1% | 无缝、非实心；末格只能按密度（4 档）表达 |
| 游标尺（细线 + 游标） | 0.625% | 完全无填充；丢失「已用面积」直觉 |
| 纯数字 + 区间色 | 0.1% | 精度最高；丢失容量直觉 |

盲文格间缝来自字形本身（点阵只占格子左侧），Unicode 无更宽盲文字形，换族才能消除；
用户选择接受缝隙、采用点阵观感。

## 4. 影响面

- `token_bar_text()`：填条计算替换为点数计算；`TOKEN_BAR_CELLS` 语义不变（20 格）。
- `smoke/footer.py`：25% / 25.6% / 40% / 80% 四组断言改为点阵字符串，并覆盖末格 1 点精度。
- `tests/test_ui_footer_approval_mode.py`：新增 `_dot_cell` 八档字形、53% 渲染、
  0.625% 相邻档差异、100% / 超限饱和四组测试。
- `docs/tui.md`、`app.css` 注释同步描述。

## 5. 验证

- `pytest -q`：943 passed, 6 skipped（含 `cell_len == 20` 的逐档宽度断言）。
- `python -m core.tui.ui_textual --smoke`：页脚段落通过，含末格 1 点精度断言。
- `rich.cells.cell_len` 对 20 格条恒为 20（字形宽度 1）。
