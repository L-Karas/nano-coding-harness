Cron 表达式:

在标准的**五段式 Cron 表达式**中，每个片段从左到右依次代表不同的时间单位。
它的经典结构在 Linux/Unix 系统中已经使用了几十年，具体的五段含义如下：

```text
 * * * * *
 │ │ │ │ │
 │ │ │ │ └── 星期 (Day of week，0 - 6，通常 0 或 7 代表星期日)
 │ │ │ └──── 月份 (Month，1 - 12)
 │ │ └────── 日期 (Day of month，1 - 31)
 │ └──────── 小时 (Hour，0 - 23)
 └────────── 分钟 (Minute，0 - 59)

```

---

### 各字段取值与特殊符号说明

每个位置不仅可以写具体的数字，还支持以下常见的**特殊符号**来灵活定义时间：

* `*` **（每）**：匹配该字段的任意有效值。例如在“分钟”位写 `*` 代表“每分钟”。
* `*/N` **（每隔 N）**：表示步进。例如在“分钟”位写 `*/5` 代表“每隔 5 分钟”。
* `,` **（枚举）**：用于连接多个离散的值。例如在“小时”位写 `9,12,18` 代表“在 9 点、12 点和 18 点”。
* `-` **（区间）**：表示一个连续的范围。例如在“星期”位写 `1-5` 代表“周一到周五”。

---

### 常见经典示例

| Cron 表达式      | 触发时机含义                      |
|---------------|-----------------------------|
| `* * * * *`   | **每分钟**都会触发一次               |
| `0 9 * * *`   | **每天早上 9:00** 触发            |
| `*/5 * * * *` | **每隔 5 分钟**触发一次             |
| `0 9 * * 1-5` | **每个工作日（周一至周五）的早上 9:00** 触发 |
| `30 22 1 * *` | **每月 1 号的晚上 22:30** 触发      |

---

> ⚠️ **特殊逻辑：日期（DOM）与星期（DOW）的“或（OR）”关系**
> 在标准 Cron 语义中，如果**日期（第 3 位）**和**星期（第 5 位）**同时被指定了具体约束（即都不是 `*`），系统通常会采用 **OR（或）
** 的逻辑。也就是说，只要满足“今天是指定的日期”**或者**“今天是指定的星期几”，任务就会被触发。
